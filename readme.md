# LittleBit's Userscripts

A repository of my userscripts, for use with Tampermonkey or another userscript extension.

This repository is replicated on [GitWorkshop/ngit](https://gitworkshop.dev/littlebitstudios.com/userscripts), [GitHub](https://github.com/littlebitstudios/userscripts), [Tangled](https://tangled.org/did:plc:ba3ftueh2aewxja4dtuhi7kf), and [Radicle](https://radicle.network/nodes/rad.littlebitstudios.com/rad%3Az7eTWinR51wPEE4zNtjnacu33HY7).

Install links in this file come from Tangled. You can use the "raw" buttons in the files on GitHub or Radicle to install from those, and direct install is not supported by GitWorkshop.

- **amazon-url-shortener:** Shortens an Amazon URL to just `amazon.com/dp/[ASIN]` and copies it to your clipboard, as that's all that's needed to share an Amazon product.
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/amazon-url-shortener.user.js)
- **atproto-inspectors:** See details about Bluesky posts and profiles using ATProto Browser, Clearsky, PDSls, or atproto.at.
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/atproto-inspectors.user.js)
- **bsky-replacer:** Attempts to go to bsky.app can be redirected to any similar client of your choosing.
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/bsky-replacer.user.js)
- **ditto-comments-page:** Leave NIP-22 comments on a page at ditto.pub.
  - ***You'll need a Nostr identity to leave comments, if you want one you can get one at the login screen on Ditto***
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/ditto-comments-page.user.js)
- **hey-palus-redirect:** Redirects most attempts to go to hey.xyz to palus.app, as Palus was/is a fork of Hey (both Lens Protocol apps).
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/hey-palus-redirect.user.js)
- **youtube-to-polycentric:** Adds a link above YouTube comments sections to open a page on harbor.social, so users of the YouTube website can see comments left by users of alternative YouTube client Grayjay.
  - ***The script's display name, URLs, and other user-facing elements have been changed to work with the new Harbor system. The file name remains the same to not break updates for users of the old Polycentric and this userscript.***
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/youtube-to-polycentric.user.js)
- **switch-nostr-clients**: Switch between different Nostr clients from the extension menu or a right-click when viewing Nostr posts or profiles on the web. Currently supports 5 clients, contributions are welcome.
  - [Install this userscript](https://tangled.org/littlebitstudios.com/userscripts/raw/main/switch-nostr-clients.user.js)
