# LittleBit's Userscripts

A repository of my userscripts, for use with Tampermonkey or another userscript extension.

- **amazon-url-shortener:** Shortens an Amazon URL to just `amazon.com/dp/[ASIN]`, as that's all that's needed to share an Amazon product.
- **atproto-inspectors:** See details about Bluesky posts and profiles using ATProto Browser, Clearsky, PDSls, or atproto.at.
- **ditto-comments-page:** Leave NIP-22 comments on a page at ditto.pub.
  - ***You'll need a Nostr identity to leave comments, if you want one you can get one at the login screen on Ditto***
- **hey-palus-redirect:** Redirects most attempts to go to hey.xyz to palus.app, as Palus was/is a fork of Hey (both Lens Protocol apps).
- **youtube-to-polycentric:** Adds a link above YouTube comments sections to open a page on polycentric.io, so users of the YouTube website can see comments left by users of alternative YouTube client Grayjay.
  - ***This currently doesn't work, as FUTO are making changes to polycentric.io***
